# Features

## Tool wheel

Hold the trigger, move toward a section, then toward a tool, and let go. Let go in the centre to cancel.
A quick tap keeps the wheel open so you can click.

The Premiere Pro wheel has eight sections:

| Section | Tools |
| --- | --- |
| Adjustment | Adjustment layer over the selection or at the playhead |
| Timeline | Cuts, ripple, markers, nest, unnest, match frame, render |
| Speed | Speed presets, reverse |
| Effects | Cross Dissolve, Dip to Black, Dip to White and other transitions |
| Color matte | A colour matte in the project, on the timeline |
| Gain | Audio gain up, down, set |
| Colour | Copy colour, paste colour, reset colour |
| Sequence | New sequence, sequence from clip, duplicate sequence |

### Layouts

Each app can have more than one layout. With the wheel open, scroll to switch.
Premiere Pro ships with a second one, **Classic** (Frame, Transform, Markers, Labels, Playback).
The wheel opens on the layout you used last. Edit layouts in **Settings › Tool wheel**.

### Your own tools

In Settings you can add a Premiere effect, a transition, a menu command or a keyboard shortcut as a tool and put it on any wheel.

## Options wheel

A second wheel with its own trigger, for app-wide actions. It works in every app.

## Orbit switch

A wheel of your open and pinned apps. Default trigger **F9**. Pin apps to keep them on it, hide ones you never want.

## Quick search

**⌥ Space** in Premiere Pro or After Effects. Type an effect, transition or command and press Return:
it goes on the selected clips. What you picked lately is listed first.

## Mouse buttons

Per app, each mouse button (middle, side buttons) can run a tool, send keys, or open the wheel.
Use **Record** to capture a key combination.

## Other apps

**Settings › + Add app** gives any app its own Tool wheel, Options wheel and buttons.
DaVinci Resolve, Final Cut Pro, Photoshop and Lightroom Classic come with ready-made tools. Other apps start with basic shortcuts you can change.

## Panel (Premiere Pro and After Effects)

**Window › Extensions › HaloCut** opens one panel with every tool. The title is a switcher.

Premiere Pro: Toolbar, Command, Studio, Grade, Motion, Transitions, Zoom, Split, Caption Styles, Retakes, Podcast, Beat, Markers, Bins.

After Effects: Kit, Type, Accents, Vector, Flow, Resize, and the shared ones.

Keep the panel open: the wheel's tools run through it.

## Appearance

13 accents and 9 backgrounds, including one light theme (Paper).
The wheels and the panel follow the theme. Over a light window they stay dark, because they sit over video.

## Settings backups

- **Save settings** writes a backup now.
- HaloCut also keeps one automatic copy a day.
- **Restore** brings back a saved copy.
- **General** has export, import and reset.

## Updates

HaloCut checks the GitHub releases of `genxnayem-svg/halocut` and shows a notice, in the tray menu too, when a newer version is out.
This needs the repository and a published release. See [Build and release](BUILD.md).
